# 两分钟标记价代理与资金费敏感性政策 R010-MARK-PROXY-v2

用户明确授权在真实标记价无法恢复时，使用现货观测代理缺失分钟，并与前值平坦代理比较。本政策是新增研究例外，不改变历史数据政策、原始归档、冻结结果或原金融核心。

## 允许范围

仅限2024-08-12 10:02与10:03 UTC，SOL、XRP、DOGE、ADA、LINK、AVAX、LTC各两根，共14根分钟标记价K线。其他币和其他时点不允许代理；任何新增缺口都会拒绝验收。BTC、ETH、BNB在该月已有完整标记价。

- **spot**：从币安官方同币USDT现货2024-08月度1分钟归档取得对应分钟OHLC，只替换缺失行。对现货归档验证官方校验和、全月44640根的时序及OHLC，不将现货成交量用于策略特征。
- **ffill**：从原始10:01标记K线收盘取得价格，对两个缺口构造相同开高低收。第二根继续使用原始10:01观测，不以第一根代理为新观测。源在10:02可见，第二根开盘时已陈旧60秒、结束时120秒；不复用资金费估值政策的60秒阈值来声称这些分钟是真实完整标记价。

spot的价格是实际现货观测，但把它当作标记价仍是代理。ffill的源价格是过去实际观测，但两个平坦K线及其振幅是构造的代理，不是新增实际观测。两者均标记`exact_mark_recovered=false`和`strict_mark_price_coverage=false`。

原金融引擎按分钟开盘、分钟不利极值、收盘的原有时序使用标记价；现货分钟高低收不用于该分钟开盘决策。交易信号、止损触发和实际成交参考继续使用原永续成交K线，不替换为现货。原费率、资金费估值规则与账户风险预算不变。

## 来源与偏离记录

原始来源保存在`data/raw/spot_klines`及原有`data/raw/markPriceKlines`中，按内容哈希保存；公开Git仍排除原始ZIP。代理完整分钟表单独保存在`data/validated/mark_proxy/{spot,ffill}/`，没有覆盖原始标记价或正常化数据。

独立manifest位于`artifacts/data/mark_proxy_runs/`，每个补入的分钟记录源、时间、OHLC、可见时刻/陈旧时间、官方归档URL与哈希。spot记录`proxy_source=spot`，ffill记录`proxy_source=last_closed_mark`。通过的是带显式代理的分钟表时序与schema验收，不是真实标记价完整性验收。原严格数据入口不会自动使用这些代理。

每个币额外统计缺口前30分钟、后30分钟有双边观测时，现货与标记价**收盘**绝对偏离`abs(spot_close/mark_close-1)`，给出样本数、中位数、P95和最大值。这只能描述邻近观测的基差，不能测出缺失分钟的实际误差，也不是标记极值或强平风险的误差上界。

## 回放与比较

```powershell
python -B -m unittest discover -s tests -p test_mark_proxy.py -v
python -B scripts/run_mark_proxy.py --prepare-data
python -B scripts/run_mark_proxy.py --recover-funding-rest
python -B scripts/run_mark_proxy.py
```

固定区间为2024-07-01至2026-01-01（结束点不含），2024年5—6月热身。用户随后追加资金费敏感性要求，因此v2固定两个标记价代理×资金费0/1/2倍×同期SIG-001/Phase 1同向3仓候选×基础/压力成本，共24个账户；每个数据情景仍是4个同期对照账户。保持完整连续日期，不剔除缺口当天，不择优数据情景、不追加策略参数搜索、不解冻2026、不启动Phase 2。

敏感性报告比较期末权益、累计收益、年化、分钟不利路径回撤、逐笔交易、每日/每小时权益、代理强平事件、执行歧义和永久停机，并列出缺口期间受影响币的持仓。原Phase 1数值门槛须在两个代理、两个成本下均通过才有条件性的数值改进依据，仍非独立验证与实盘资格。

两种替代结果相同，只能说明本次回放对两种指定替代不敏感。没有真实标记价，不能证明实际缺失分钟绝不触发强平或账户保护。结果文件会保留这些边界。

## 资金费归档例外与条件放行

首次数据准备中，两种标记价代理均已做好，但9个资金费分区REST仍返回403：LTC的2025-11，以及BNB、SOL、XRP、DOGE、ADA、LINK、AVAX、LTC的2025-12。原失败manifest保留在`MARK-PROXY-DATA-20261016T055736Z-250f2435`。

用户明确追加：允许先用官方校验归档开展0、1、2倍资金费敏感性；结果差异很小时，将9个分区标注为“官方校验归档、未获REST复核”用于本次研究。代码仅对上述9个白名单分区启用这个例外，保留`funding_rest_verified=false`，不会构造假REST响应或声称精确结算标记价已恢复。

资金费率来自官方归档，时序和区间仍严格检查；没有REST精确结算价时使用原有的上一根已闭合标记K线、最大60秒陈旧估值规则。其他已通过REST核对的分区保持原来源。两个标记代理的funding valuation会分别生成，所有文件按哈希保存。

本次资金费敏感性作用于**全扩展窗口**，原归档率分别乘0、1、2，正负资金费收付同时缩放；数量预算中的资金费缓冲不变。2倍不是只加倍支出的最坏成本情景，也不代表归档误差一定有这么大。

运行前固定“差异很小”的筛查线：对每个标记代理、每个账户，三种资金费假设的期末权益范围≤0.10USDT，年化范围≤0.10个百分点，不利路径最大回撤范围≤0.10个百分点；交易决策时点/方向/退出原因、永久停机、代理强平、执行歧义和数值门槛判断保持一致。数量和净盈亏可以因权益变化而微调。任一项未满足，就不按这个条件宣称9个分区可以忽略复核。

单独报告9个分区实际发生的持仓资金费事件和净收付。如果期间没有持仓，零差异只能说明当前策略没有暴露于这些数据，不能证明资金费数据准确。若全窗口资金费压力差异大，但9个分区没有暴露，也不能把差异直接归因于这9个分区。

## 本次REST恢复与最终结果

资金费0与1倍的暂定回放已超过事先声明的0.10USDT权益差异线，因此按用户要求继续解决403。观察到同一官方接口、同一历史窗口，`limit=1000`返回403，而文档支持的`limit=100`返回正常结果；具体服务器拒绝原因未得到证明。恢复器只用正常公开GET和有界时间游标，不改变访问权限，也不读取2026历史。

9个分区均已通过官方REST复核，共834个时点及费率与原归档完全一致。每页原始响应、URL、哈希和拼接来源单独保存。REST精确结算标记价有484处与原先闭合K线估值不同，所以用新估值重新执行同一24账户矩阵。初次暂定矩阵`MARK-PROXY-SENS-20261016T061648Z-1662c1ee`及失败准备清单保留；最终矩阵为`MARK-PROXY-SENS-20261016T062546Z-4ac1fc42`。两批共48次账户执行属于同一组策略与数据假设的来源纠正重放，没有依据结果修改策略或阈值。

当前manifest为`MARK-PROXY-REST-RECOVERED-20261016T061924Z-d5198124`，`funding_rest_verified_all_partitions=true`；9个资金费例外无需条件放行。14根真实标记价仍未恢复，保持显式代理和`strict_mark_price_coverage=false`。

最终结果：两种标记代理在所有资金费倍率下的逐笔交易、每日和每小时权益一致；缺口时均没有持有受影响币。资金费0/1/2倍的期末权益基础为110.8694/110.4095/110.0376USDT，压力为107.9506/107.6119/107.4003USDT。未达到“资金费差异很小”的事前标准，但REST已通过实际请求恢复，不需要用敏感性替代数据复核。

按原始费率计入，基础/压力累计收益+10.41%/+7.61%、折算年化6.81%/5.00%、不利路径最大回撤8.68%/8.50%，无停机、代理强平或执行歧义。候选与SIG-001同期对照的交易和每日权益完全一致，因此同向3仓没有提供改进，未通过相对年化改善及bootstrap改善门槛，Phase 2保持关闭。
