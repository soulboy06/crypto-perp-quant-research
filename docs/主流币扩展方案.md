# 主流币扩展方案 UNIV-001-v1

**数据范围调整记录：完整2023—2025十币数据存在资金费REST 403和2024-08-12两分钟标记价源缺口；按十币回放前固定的UNIV-COVERAGE-001-v1，首次对比使用2023-01-01至2024-07-01。两币/十币使用相同日期，未按策略收益选时间。完整期目标和已下载数据保留，结果见[主流币扩展结果](主流币扩展结果.md)。**

2026-10-16，用户要求先增加主流币种；暂停上一轮提出的跨币方向过滤方案，本轮不加入新因子。

研究币池固定为BTCUSDT、ETHUSDT、BNBUSDT、SOLUSDT、XRPUSDT、DOGEUSDT、ADAUSDT、LINKUSDT、AVAXUSDT、LTCUSDT，共10币。新增8币均核对公开合约状态、USDT保证金、永续类型和上线日期，早于2022年11月热身起点。当前主流币名单不是历史时点可得名单，存在幸存者偏差，不把扩展回测称为无偏验证。

原first_round.toml、DATA-001-v1、EXEC-001-v1及全部旧结果保留不变；新入口为configs/universe_expansion.toml。币池按当前主流程度固定，不根据2023—2025收益删币、排名或赋权；同一时刻按BTC、ETH、BNB、SOL、XRP、DOGE、ADA、LINK、AVAX、LTC顺序尝试，后续币种可能因共享资金或风险预算不足而被拒单。

所有币种共用100USDT，1USDT=1USD为研究近似。单笔风险0.5%，全部已开/待成交止损风险合计1%，基准总名义敞口1倍，最高有效杠杆10倍，逐仓、关闭自动追加、同币先平再反向。原20%回撤保护、3%日亏损暂停、50USDT本金停止线、20%自由抵押预留全部保留，不给每个币另开100美元账户，也不为提高成交数量放宽约束。

策略沿用R004：48小时突破、小时EMA200、最近完整四小时EMA20/50方向、24小时效率ER≥0.30；收盘确认后延迟60秒，原2ATR止损、小时EMA50退出、72小时持仓期限。两种成本保持原值，实际结算资金费单独计入。BTC/ETH沿用原规则快照以复现对照，新增币采用新保存公开规则；历史逐时订单过滤器和维持保证金档位仍未验证。

数据仅为2022年11—12月热身和2023—2025开发历史；2026年历史继续锁定。新增8币需要912个官方月度分区，每个币都包含1分钟行情、标记价和资金费。旧BTC/ETH的228个分区直接复用，不重新下载或重复全量校验。缺口只用官方观测源修复，不填造价格、不默默剔除数据不足币种。资金费间隔变更保留原始事件时间与报告间隔，经REST逐条核对，并记录转换情况。

固定执行两个新增候选账户：十币组合×基础/压力成本。另用原两币×两种成本做实现复现，核对保存的逐笔交易与每日权益；不将复现对照算成新策略。结果包含整体年化、压力路径回撤、年度收益、每币贡献、拒单、保护事件与执行歧义。扩币接入成功不代表收益一定提升，也不自动取得正式选模或实盘资格。

命令（Python 3.12，无第三方依赖）：

```powershell
Set-Location -LiteralPath 'D:\量化'
python -B scripts/prepare_universe.py
python -B scripts/run_universe.py
```

准备器支持复用已完成的同方案分区；运行器要求全部10币覆盖完整后才回放。已有数据与结果时直接查看artifacts/data/universe_latest.json和artifacts/backtests/universe_latest.json，无需重复执行。最终汇总写入docs/主流币扩展结果.md。
