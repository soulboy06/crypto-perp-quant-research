| BTC、ETH 标记价 2023-02 | 各缺 2023-02-24 整天 1,440 分钟 | 使用同币同日官方日包，逐条校验后纳入 |

2024 年 8 月修复时，每币先确认月包与日包 1,438 条重叠价格一致，再确认 REST 返回的相邻两分钟与已有归档 OHLC 一致。仅加入两条实际返回的缺失记录。API 响应没有交易所另发的 CHECKSUM；保存的是请求 URL、原始响应及本地 SHA256，不能称为官方签名校验。没有合成价格、前值填充或未来收盘价填充。

原始失败清单及首次只修复两份月包的清单均保留，没有覆盖历史结果。最终清单明确列出原始月包缺口、日包和 REST 补充来源及修复后的内容哈希。

## 使用与边界

`python scripts/prepare_development.py` 会对冻结范围重新准备月包，可复用哈希匹配的本地 ZIP，仍核对官方校验和并重新审计；有缺口时返回未通过，不自动把它当成完整数据。

```powershell
python scripts/reconcile_development.py artifacts/data/full_runs/DEVELOPMENT-20261015T063811Z-f5b56f9c/manifest.json
```

该命令对缺口寻找官方日包，必要时对小范围标记价缺口请求官方 REST，生成新的独立修复报告。最终必须通过整月覆盖和重叠一致性检查。不能泛化为允许任意缺失数据的插值工具。

资金费代理继续遵守 DATA-001-v1，只用于结算估值，不作为提前可见的交易信号。精确价与代理价分别标记。数据政策未修改，首轮研究配置也未修改。

历史开仓过滤条件、维持保证金档位、实际手续费与强平执行仍缺完整证据。此次没有运行策略、参数搜索或保留期评价；执行准备度仍为 false，不能由数据验收推导出盈利能力。
