# 共享账户账本：LEDGER-001-v1

本模块只处理模拟账目，不发送交易指令。BTC、ETH 共用初始 100 USDT，按已冻结的研究近似视为 100 美元；没有按币种分别发放 100，也没有把杠杆再次乘到盈亏上。

## 账户恒等式

账户净值 = 自由现金 + 未成交订单预留 + 各逐仓钱包余额之和 + 未实现盈亏。

另一条独立核对式为：初始资金 + 已实现盈亏 + 净资金费收入 − 成交手续费 + 未实现盈亏。每个成功事件均核对两式；转入保证金和预留资金只是账户内部移动。价格、数量和费用以 Decimal 计算，持久化时保存十进制字符串。

## 已实现行为

| 事件 | 处理 |
|---|---|
| reserve | 同时检查现有与待成交总敞口、止损风险及共享现金；拒绝同币加仓、同时反向持仓或超预算订单 |
| fill | 支持部分成交，按成交份额释放预留，计入逐仓钱包并扣手续费；剩余订单继续占用预算 |
| cancel | 释放尚未成交部分的预留，不退还已成交手续费 |
| mark | 必须提供所有持仓标记价，变动未实现盈亏；开仓前要求现有持仓的标记价与事件时间相同 |
| funding | 多头在正费率时付款、空头收款；代理价格不得来自未来，年龄上限 60 秒；阻止同币同时间重复结算 |
| exit | 仅减仓，支持部分平仓；按比例释放实际逐仓钱包，确认盈亏并扣退出手续费；清空后才能反向开仓 |

订单数量必须满足调用方提供的步长、最低数量、最高数量及开仓最低名义金额。成交价格已经包含调用方模拟的点差与滑点，账本只另扣手续费，避免重复扣滑点。模拟入场若价格变化导致预留或风险预算不足，会原子拒绝；执行器应先重新评估或取消，不能把这种机制用于处理已经发生的真实成交。

研究默认的日亏损 3% 暂停开仓、峰值回撤 20% 永久停用及净值 50 美元最终停止均保存为账户状态。触发时取消剩余开仓订单，允许退出和继续处理持仓应付资金费。日界线必须有 UTC 零点的完整标记价事件，不允许跨过多个交易日悄悄重置。净值跌破阈值时照实记账，不把亏损裁剪到阈值。被动超过当前账户杠杆场景时标记需要减仓，不能假装行情变化后杠杆仍必然受限。

## 资金费划转约定及证据边界

调用方必须显式传入 `available_first_credit_cash_research_v1`：支出先扣自由现金，剩余扣该逐仓钱包；收入计入自由现金。不会主动追加保证金。当前[币安资金费说明](https://www.binance.com/en-AU/support/faq/detail/360033525031)支持先可用余额、后持仓保证金的扣款顺序；收入入自由现金的处理及整套约定在历史研究期尚未逐日核实，不能称为历史交易所账本的精确复刻。当前 FAQ 的更新日期为 2026-03-06，不能倒推其所有文字在 2023 年已生效。

该 FAQ 还提示实际结算处理可能有约 15 秒偏差。账本按提供的资金费事件时间消费当时持仓；未来执行器必须明确同一分钟内开平仓与结算的先后、处理临近结算的歧义，不能靠一分钟收盘价推断真实成交顺序。资金费估值仍服从 DATA-001-v1，近似价格必须保留来源时间与标记。

账户恒等式也参考[币安钱包说明](https://www.binance.com/en-KZ/support/faq/detail/5d62f8be18d24544b5b6156094c16bf7)；这里并未把跨仓余额当作可自动救助逐仓的抵押。

## 持久化与复查

可选 SQLite 日志在事务中写入事件、状态摘要和摘要链，成功提交后才发布内存状态。相同事件 ID、相同内容重放不会再次扣款；同 ID 不同内容会拒绝。重启逐条重放并验证结果，配置、费用场景或规则绑定不同也会拒绝打开。摘要链能发现被修改记录或内部序列不一致，不能独立证明日志末尾从未被删除；没有声称防篡改安全存储。仅支持单写入者。

入口为 `src/perpquant/ledger.py`。运行 `python scripts/demo_ledger.py` 可产生独立合成账目例子和重启证据。该例的价格、过滤条件、保证金档位全部是测试夹具，不能放入正式 `artifacts/rules/margin_rules.json`，例子的正盈亏没有策略收益意义。

## 仍未完成

真实历史过滤条件与维持保证金档位仍需证据。规则对象必须有有效期和来源标识，但账本不会替调用方证明其真实性。检测到逐仓强平条件会标记 `liquidation_required` 并停用新开仓，尚未实现真实强平成交、强平费用、部分清算或 ADL。峰值/日损停用及超杠杆减仓也需要执行器实际安排退出。现已接入 EXEC-001-v1 分钟研究执行器、两个固定策略与绩效统计，结果见《首轮回测结果》。分钟路径与规则均有代理限制，正式历史适用性验收仍为 false。持仓剩余止损风险只预留未支付的退出摩擦，不重复预留已经支付的入场摩擦。
