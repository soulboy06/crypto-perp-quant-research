## 实际发现

两币各有 60 个资金费事件不是整秒时间戳，最大毫秒偏移为 23 毫秒。解析保留微秒精度的规范时间，不将其取整到 8 小时网格，也不使用“事件时间必须恰好等于整点”作为入账条件。

REST 的 186 个历史事件中，markPrice 全部为空。它不是零价，也不是费率缺失；不能静默跳过资金费，不能宣称取得了精确结算标记价格。

## 估值补充政策 DATA-001-v1

政策在任何策略回测之前固定，配置见 [data_policy.toml](../configs/data_policy.toml)，属于 R001-v1 的执行数据补充，不改变策略参数、风险预算或账户预算。

1. 有真实结算标记价时优先使用，并记录来源；当前样本没有该字段。
2. 缺失时使用资金费事件时刻之前最近一个已闭合 1 分钟标记价条目的收盘价。闭合可得时间不晚于事件时间，最大年龄 60 秒。
3. 原始资金费事件时间不变。没有合格历史价格就报错，不用零价、不跳事件、不借用正在形成的分钟线最终收盘价。
4. 该值明确标为价格近似，不能声称精确复现交易所资金费扣款。估计误差和资金费敏感性须在后续交易报告披露。
5. 当前可得性检查只覆盖 2023-01-01：两币各 3 次事件，共 6 次。所用条目闭合时间不晚于事件时间，样本中年龄为 0 或 8 毫秒。

这里的可得时间是历史分钟闭合时间近似，不是测得的实时网络接收延迟。资金费结算估值与用于生成信号的信息可得性仍需分别审计。

首次结构报告生成时估值政策尚未固定，所以旧报告的 funding_valuation_policy_frozen=false 保留历史状态；后来的 VALUATION 报告记录 DATA-001-v1。原始报告不改写。
