# 公开仓库说明

这是加密货币USDT本位永续合约的离线研究项目，包含未通过的实验与风险事件记录。当前没有经过独立验证的可实盘策略，不连接交易账户、不保存交易密钥，也没有实盘下单功能。

研究币池为BTC、ETH、BNB、SOL、XRP、DOGE、ADA、LINK、AVAX、LTC。所有币共用100USDT模拟本金，单笔风险预算0.5%、全部已开与待成交止损风险预算合计1%，最高有效杠杆上限10倍；这些预算不是实际亏损上限。完整规则、代理假设和失败结果均在配置及报告中保留。

## 随仓库提供的内容

- `src/`、`scripts/`、`configs/`、`tests/`：研究实现、固定方案和关键测试。
- `docs/`：研究方案、各轮结果、亏损归因和执行限制。
- `artifacts/`：保存的运行清单、逐笔交易、净值、事件、源代码快照以及未完成数据任务记录。失败/调试记录保留，不能当成有效策略证据。
- `data/validated/`：已规范化的公开行情、标记价、资金费及因子表，约505MiB。部分后续分区不完整，文件存在不代表对应时期可做完整回测，必须以运行绑定的清单为准。

`data/raw/`中的官方原始ZIP、校验和及HTTP原始响应约936MiB，未放入Git历史，本机文件不删除。来源URL、校验和与下载/准备脚本已保留。用到原始归档的审计或数据重建命令需要按清单重新获取原始数据，公开接口可能返回403或存在历史缺口；主要已保存价格策略回放直接读取随仓库提供的规范化数据。

数据来源包括[币安公开数据归档](https://data.binance.vision/)与[币安公开数据项目](https://github.com/binance/binance-public-data)，以及币安公开合约规则和历史行情/资金费REST接口。数据来源与适用条件仍归原提供方，本仓库不另行声称拥有原始市场数据的权利或提供数据准确性保证。

## 可复跑入口

使用Python 3.12，主要研究与测试只依赖标准库。请在克隆后的仓库根目录运行，不必使用报告中原开发机器的`D:\量化`路径。

```powershell
python -B -m unittest discover -s tests -p test_signal_quality.py -v
python -B scripts/run_signal_quality.py
```

最近一次固定信号实验见[十币信号质量优化结果](十币信号质量优化结果.md)。上述命令会生成新的独立运行目录，重写可变的最新结果指针，不覆盖旧运行的金融结果；无需为了阅读已有结论重新回放。

原十币对照：

```powershell
python -B scripts/run_universe.py
```

两者采用共同完整窗口2023-01-01至2024-07-01（结束时点不含），另有2022年11—12月热身。十币完整2023—2025结果因历史数据缺口尚未提供。旧BTC/ETH实验有完整2023—2025数据，不能把两种窗口的年化直接混为一谈。2026保留历史未下载或读取。

## 已知限制

当前主流存续币名单造成幸存者偏差；开发历史已经多轮观察。历史订单过滤器、维持保证金和分钟内事件顺序仍有代理假设。最近实验仍亏损，并出现AVAX止损与代理强平同分钟的歧义和随后的停机；回撤变小不等于持续交易下的稳健改善。

`.gitattributes`关闭自动换行转换，以保持清单记录的SHA-256字节一致性。报告中的本机绝对路径属于历史来源信息，运行脚本以其所在仓库根目录解析实际输入。
