# 第十一轮方案 R011-v1-percoin：分币种趋势过滤器

状态：草案（proposal）。未验证，不替换冻结基准，不连接实盘。
配置入口：[eleventh_round.toml](../configs/eleventh_round.toml)。
日期：2026-10-16。

## 一、为什么做这个

研究假设：小时突破可能在低趋势强度时反复止损；本轮验证分币种趋势过滤是否改善结果。

| 窗口 | 市场状态 | 十币策略结果 |
|---|---|---|
| 2023–2024H1 | 开发期，2023 年发生代理强平/歧义停机 | SIG-001 −5.82% |
| 2024H2–2025 | 扩展验证，现货代理、真实资金费 | SIG-001 +10.41% |

窗口间差异不能直接归因于趋势，不能证明过滤器有效。−14.59% 属于未加 SIG-001 距离过滤的另一策略，不作为本轮同策略对比。

R011 只做一件事：加个天气预报，震荡市不新开仓。

## 二、预注册设计（不调参）

| 项目 | 取值 | 依据 |
|---|---|---|
| 指标 | Wilder ADX(14) | 教科书标准公式 |
| 周期 | 日线（UTC 午夜收盘）| 状态层必须慢于信号层（小时级）|
| 标的 | 每个币各自 | 分币种：每个币用自己的日线 ADX 判断，不拿 BTC 代表全市场 |
| 阈值 | ADX > 25 为趋势市 | Wilder 教科书阈值，**未调参** |
| 门控 | 非趋势市禁止新开仓 | 平仓和持仓管理不受影响 |
| 失败默认 | ADX 未就绪时禁止开仓 | fail-closed |

**反过拟合声明**：每币各自计算 ADX，阈值 25、周期 14 事前固定，不代表最优参数或收益保证。禁止根据已观察结果试 20/25/30 选最优。

## 三、实现

- `src/perpquant/regime.py`：增量 Wilder ADX(14)，日线由分钟 K 线聚合，严格只用已收盘的日线，无前视。8 个单元测试通过（含增量/批量一致性、无前视、fail-closed）。
- `src/perpquant/regime_account.py`：`RegimeAccount(CappedAccount)`，先生成 SIG-001 信号，再按币种过滤趋势，最后预留同向名额。替换同批信号时释放原名额；退出和原有资金、风险预算不变。`minute()` 和预热期喂分钟数据。
- 运行器 `src/perpquant/regime_run.py` + `scripts/run_regime.py`：4 个账户（Phase 1 对照 + R011 候选，各 × base/stress），沿用 Phase 1 的数据与冻结检查。

## 四、验证计划

1. **开发期诊断**（2023–2024H1）：预期过滤器减少震荡市交易、降低亏损。不作为验收。
2. **扩展验证**（2024H2–2025）：对照为同期 Phase 1。门槛沿用 Phase 1 框架（净收益为正、≥30 笔、年化改善 ≥1pp、回撤 ≤20%、无停机/强平/歧义、Calmar 不降、bootstrap 下限 >0）。
3. **归因**：保持同期数据、成本和风险预算相同，比较新增状态门的影响；不据此宣称未来盈利。

## 数据入口与执行

本 PR 依赖 [PR #2](https://github.com/soulboy06/crypto-perp-quant-research/pull/2) 的数据修复，先合并 #2 再合并本 PR。复用 `phase1_data.window_config` 与 `phase1_run.corpus`，不另建数据政策。

- 开发期诊断读取冻结 SIG-001 原始数据清单；2022 年 11–12 月预热，不读取扩展期指针。
- 扩展期读取 `artifacts/data/mark_proxy_latest.json` 的 `spot` 或 `ffill` 场景；2024 年 5–6 月预热。要求资金费全部完成 REST 复核，资金费倍率固定 1 倍。
- 沿用文件哈希、数据清单绑定和 14 根代理分钟 K 线白名单；缺数据即停止，不回退到不完整数据。
- 两套代理分别运行并比较权益和交易路径，不按收益挑选代理。

```powershell
python -B scripts/run_regime.py --scope reproduction
python -B scripts/run_regime.py --scope extension --proxy-scenario spot
python -B scripts/run_regime.py --scope extension --proxy-scenario ffill
```

验收读取真实引擎字段：`round_trips`、`max_adverse_bound_drawdown`、`calmar`、`halt_reasons`、`liquidation_proxy_events`、`execution_ambiguities`。不使用累计收益替代年化或 Calmar。每日权益按相同日期配对，调用原统计函数做 14 天循环区块重采样 2000 次、种子 20261016，年化改善 95% 区间下限须大于零。

`status: completed` 只表示运行结束。`gates.numerical_checks_passed` 表示两个成本均通过数值门槛；`gates.overall_passed` 还要求是扩展验证。缺少账户、指标或有效配对权益时不通过；开发期诊断永远不能替代扩展验收，正式选模资格始终为 false。

回归测试覆盖真实十币配置和三套数据清单、缺失结果不得通过、真实风险字段、实际 bootstrap、趋势过滤先于占名额、替换批次释放名额、震荡状态仍可平仓。

## 五、已知局限

- ADX 本身滞后，会错过部分趋势起点；过滤器不改变原有退出规则。
- 每币独立计算 ADX，不代表各币风险独立。当前币池有幸存者偏差，历史订单和维保规则仍是代理。
- bootstrap 不修正多轮选择偏差，不是未来盈利概率。
- 2024H2–2025 仍是扩展验证，不是独立样本外；2026 继续冻结。
- 选模资格 false；不连接实盘。
