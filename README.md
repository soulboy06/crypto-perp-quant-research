## 当前可用命令

要求 Python 3.11+；本轮实际使用 Python 3.12.10，无第三方依赖。先进入项目目录：

```powershell
Set-Location -LiteralPath 'D:\量化'
python -B run.py check-config
python -B run.py size-preview --leverage-cap 10
python -B run.py check-readiness
python -B -m unittest discover -s tests -v
```

`check-config` 只检查配置约束。`size-preview` 用固定的合成价格和合成订单规则演示数量预算，不是 BTC／ETH 真实行情或下单建议，也不检查强平。`check-readiness` 当前应返回 ready=false 和退出码 2，这是旧设计的静态库存检查；当前研究执行器已能运行，真实历史规则与完整强平模型尚未验收。

```powershell
python -B scripts/probe_sources.py
```

来源探测只 GET 当前公开规则，对 2023 归档作 HEAD 检查，不读取历史价格记录。新版每次写入 artifacts/setup/source_probes/ 下独立目录；初始规则与报告保留未变。样本下载器按内容哈希保存原始数据和校验和，另建唯一运行清单。完整开发期准备与本地复查命令见下文；研究回测命令见下文；没有实盘下单命令。
